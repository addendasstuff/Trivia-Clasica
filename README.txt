TRIVIA CLÁSICA

Archivos:
- index.html
- style.css
- script.js
- data/config.json
- assets/fondo-principal.mp4

IMPORTANTE:
Esta versión guarda configuración, mute, récord y partida en localStorage para que funcione directamente como proyecto HTML estático.
El requisito original pide escribir /data/config.json en el servidor. Para cumplir literalmente ese requisito hará falta conectar un backend/API que lea y escriba ese archivo.

Para ejecutar:
1. Mantén la estructura de carpetas.
2. Abre index.html con un servidor local (por ejemplo Live Server).
3. Añade tus archivos de música e iconos en assets con estos nombres:
   - musica-juego-1.mp3
   - musicOn-icon.png
   - musicOff-icon.png
